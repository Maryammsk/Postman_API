# Postman API Testing Assignment 🚀

This repository contains API tests for the Simple Books API using Postman.

## 🔧 Collection Details

- **API Tested**: [Simple Books API](https://github.com/vdespa/introduction-to-postman-course/blob/main/simple-books-api.md)
- **Methods Used**:
  - GET
  - POST
  - PUT
  - PATCH
  - DELETE
- **Features Implemented**:
  - Base URL stored as environment variable
  - Random data generation using scripts
  - Chai assertions
  - JSON response parsing and logging
  - Failed test case (intentional)
  - Pre-request and test scripts
  - Passing variable values between requests

## 📂 Files

- `SimpleBooksAPI.postman_collection.json` – Postman collection file
- `SimpleBooksAPI_environment.json` – Environment variables (optional)

## ✅ How to Use

1. Open Postman.
2. Import the collection and environment.
3. Run the collection using Collection Runner.
